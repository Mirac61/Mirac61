## Projekte

### 🐚 [mysh](https://github.com/Mirac61/mysh) — Unix Shell in C++

Eine Shell komplett from scratch — kein Framework, kein Wrapper. Prozesse, Pipes, Redirects, Signalhandling, Tab-Completion und Git-Integration, alles selbst implementiert.

<details>
<summary>Technische Details</summary>

<br>

- Kaltstart in **~9ms** — schneller als fish (~14ms)
- **0 Memory Leaks** — verifiziert mit `leaks` und Valgrind
- Direkte Syscall-Arbeit: `fork()`, `exec()`, `pipe()`, `dup2()`

</details>
