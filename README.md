### Projects

**[mysh](https://github.com/Mirac61/mysh)** — Unix shell in C++

Written from scratch: processes, pipes, redirects, signal handling, tab completion,
git integration. Cold start around 9ms, no memory leaks under Valgrind.

**[VentoryGo](https://github.com/Mirac61/Invoice)** — Invoice backend in Go

REST API with Gin and PostgreSQL. Money as int64 cents, VAT rates as integer basis
points, client-side UUIDs — decisions made deliberately, not by framework default.
