## Projekte

### 🐚 [mysh](https://github.com/Mirac61/mysh) — Eigene Unix Shell in C++
> Eine vollständige Shell von Grund auf aufgebaut – mit Prozessmanagement, Pipes, Redirects, Git-Integration und ASCII-Animationen.

- Startet in **~9ms** – schneller als fish (~14ms)
- **0 Memory Leaks** (verifiziert mit leaks & Valgrind)
- Implementiert: `fork()`, `exec()`, `pipe()`, `dup2()`, Signalhandling
- Eigene Tab-Completion über readline
